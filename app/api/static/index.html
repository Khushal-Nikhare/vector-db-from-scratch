How IVF-Flat Works

  • Voronoi Partitioning: The 50,000 vectors are partitioned into 100 Voronoi clusters using K-Means.
  • Centroid Probing: Each query first calculates distances to the 100 centroids.
  • nprobe Control: The nprobe parameter dictates how many nearest clusters are selected.
  • Candidate Filtering: Only vectors inside those selected inverted lists become candidates for similarity evaluation.
  • Recall vs Speed: Higher nprobe inspects more clusters, improving recall toward 100% while increasing candidates and latency.
